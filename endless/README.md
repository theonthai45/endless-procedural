# Endless

Four procedurally generated worlds, made to be left running as displays.

| Folder | Piece |
|---|---|
| `shan-shui/` | Endless Shan Shui: a Chinese ink landscape painted as it unrolls |
| `survey/` | Endless Survey: a topographic map of land that doesn't exist yet |
| `street/` | Endless Street: shophouses, Haussmann blocks, canal houses, Tokyo side streets and brownstones |
| `koi-pond/` | Koi Pond 锦鲤池: a top-down koi pond you can feed (needs WebGL2) |

Open `index.html` in a browser to choose one. No build step or server needed; you can also host the folder as-is (for example on GitHub Pages).

Controls: in the scrolling pieces, `Space` pauses and `H` hides the controls; on touch devices, tap the scene to bring hidden controls back. In the koi pond, tap the water to feed the fish; `H` hides the UI, `F` goes fullscreen and `S` switches style.
